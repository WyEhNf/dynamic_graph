Implement cache_trace(capacity, operations), a pure simulation of a bounded cache. Call checked_capacity from helpers.py exactly once at entry, and use its returned value. Each operation is (time, action, key, value, ttl). All times are nonnegative integers and nondecreasing. Keys are strings. 'put' requires an integer value and nonnegative integer ttl; 'get' requires both value and ttl are None. Unknown actions and any invalid field raise ValueError, including in operations after capacity-zero puts. Before each operation, remove entries whose expiry<=time. A put replaces an existing key, makes it most recently used, and sets expiry=time+ttl. ttl=0 removes that key without adding it. With positive capacity, evict least recently used entries until within capacity. A get appends the cached value or None to a results list; a hit becomes most recently used. Capacity zero stores nothing. Return (results, final_values), where final_values is a new dictionary of key to value for the remaining entries; expiry and ordering are not exposed. Never mutate operations. Preserve the existing RELEASE_TAG constant and compatibility(value) function unchanged. Return only the complete target file.
Target file: solution.py. Return its complete content. Existing dependencies must stay available.
