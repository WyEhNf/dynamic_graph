# 强制 DAG 区间的 COPY 必要下界

这是本地身份模型下的数学必要条件，不是官网授权范围的判定。前提：原指令各发射一次；有序参数引用保持原节点身份；只插入 COPY；禁止等值节点合并、重新读取 GET、重计算、spill。只接受无原 COPY、GET/SET 名称各自唯一且两组不相交、GET/SET/ADD/MULW 的原 JSON。因此不存在新增内存顺序的争议。未知操作、寄存器别名或已有 COPY 均不适用。

令窗口 W=2^b。选择两个原节点 A、B，要求 A 是 B 的严格祖先。选 k 个互异原值，0<k<W；每个值均为 A 的严格祖先，并有一个原直接消费者为 B 的严格后代。这些值必须在 A 发射后到 B 发射前持续存活：一旦其所有历史结果离开 W 窗口，COPY 无法恢复其身份，未来消费者便不能引用它。其他等值原节点不可以恢复该身份。

在每次下一指令即将发射的坐标，最新副本的年龄（回溯距离）是互異整数 1..W。所选 k 个值的年龄和 S 满足

    k(k+1)/2 <= S <= k(2W-k+1)/2.

故任意两端点之间的年龄和总变化最多 k(W-k)。注意端点坐标为“下一条指令之前”，不是上一条指令引用参数时的坐标；所有值此时仍需要保留。

任何不产生所选身份的指令发射后使其年龄和增加 k。所选身份的 COPY 在发射前，被引用副本年龄 d_used<=W，而该身份的最新副本年龄 d_latest<=d_used；COPY 发射后其最新年龄为 1，其他 k-1 个年龄各增 1。年龄和变化为 k-d_latest>=k-d_used>=-(W-k)。一个 COPY 只能更新一个身份。COPY 可以合法引用尚在窗口内的较老副本；证明并不要求参数总指向最新副本。

取从 A 完成后到 B 发射前的区间。令 M 为“ A 的严格后代 ∩ B 的严格祖先”，L=|M|。任意合法拓扑序必须在该区间发射全部 L 个互异原节点。所选身份已在 A 之前各产生一次，故这些 M 节点不能再次产生所选身份。其余原节点、其他身份的 COPY 只增加所选年龄和，可以保守忽略。若区间发射 C 个 COPY，其中属于所选值的数目至多 C，那么

    S_end - S_start >= k L - C (W-k),
    S_end - S_start <= k(W-k).

因此总 COPY 数至少 max(0,ceil((k L-k(W-k))/(W-k)))。不同证书区间可能重叠，所以只取多证书下界最大值，绝不求和。

算法用 DAG 位集合提议 A/B 和所选身份；独立检查器从原 JSON 的参数距离重新恢复原索引，用独立 DFS 验证 A/B 祖先、所选身份与未来直接消费者和 M 的节点计数。提议器采样锚点只影响界的强弱，不影响已通过的证书效力。8192 节点/250ms 是离线提议限制；超出或预算失败标未给出下界，不解释为无解。精确年龄状态 oracle 的有界完整搜索用于反例审计，不代替上面的数学推导。

R93 对原 336 输入计算的 11.2321% 是每输入下界 C/(N+C) 的等权平均，不是 COPY 总数汇总比；47 个已有身份容量无解实例仍保留。没有输出的实例不因为下界有限而被当成可解。272 个成功输出逐一均不少于下界，仅是额外反例检测，不能独自证明必要条件。
