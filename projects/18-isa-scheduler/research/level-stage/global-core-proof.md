# 不可比 DAG 核心节点的 COPY 下界

使用 forced-cut-proof.md 的相同原一次/精确身份/COPY-only 语义及年龄和不等式。选择 k 个共享 GET 原身份，0<k<W。

定义核心 M：其中每个原节点 i 均为所有所选 GET 的严格后代，且对于每一个所选身份 s，都存在一个 s 的直接消费者严格处于 i 的后代。

对于每一份合法拓扑序，所有所选 GET 均在每个 i 之前出生，所有所选 GET 的最后一次原消费均在每个 i 之后。令 P 为所选身份中最后一个出生节点的下一发射坐标，Q 为所选身份最早的最后一次原消费之前的下一发射坐标。若 M 非空，则 P<Q，而且所有 i 属于(P,Q)间必须发射的原节点。M 中节点不要求互相可比；其数量 L 是该共同持续存活区间中的互异原节点数量下界。

年龄和范围 k(W-k)，每个 M 原指令使其增长 k，每个 COPY 至多减少 W-k，所以

    C >= max(0,ceil((kL-k(W-k))/(W-k))).

这里选定 GET 不能在区间内被任何其他原节点重新产生；等值别名/重读均被排除。M 之外的原指令、非所选身份COPY增长年龄和，忽略它们只使必要界更弱。不同所选集合的区间可能重叠，取多证书MAX，不能相加。

提议器从解析图的祖先/future 位集合算 M，最多12个候选根、1024份子集、8192节点、250ms。独立 raw checker 重建直接依赖：对每一个 s 用正向 DFS 得到出生后的严格后代；从它每个直接消费者的参数向后 DFS 得到消费之前的严格祖先。所有这些集合交集恰好为 M。检查器不调用提议器、ParsedBlock、调度器图闭包；使用原 JSON 节点索引核验集合大小。采样和预算失败不构成无解证据。
