# 题面与本地测试契约

来源：https://www.chaspark.com/#/races/competitions/1326691788365586432 ，复核日期2026-10-10。用户明确没有官方测试包，要求自行设置测试；本项目据题面设定测试，不等待未提供材料。

## 已核实题面

- 输入为朴素/分块Cholesky的C源码，分析并生成表示算子符号依赖的Metadata。
- Runtime读Metadata，面对动态Shape计算FP64下三角L，N为3..10000。
- 二进制首部4字节M，之后每矩阵4字节N、N×N×8字节行优先double；输出同结构。
- Metadata占15分，计算耗时占85分，文件IO不计入计算性能；真值完全一致是硬门槛，硬编码不得分。
- 官网朴素源码图片已读取并转录：右看更新，`L[ii]=sqrt(A[ii]-L[ii])`，列除法与后续累加，使用div/madd helper。
- 官网没有给出div/madd定义、完整分块C源、正式数据包及评测CPU细节。

## 当前验证范围

- 13类实际C源，完整基础188次严格C/VM/并行对照；最新quick162次对照与24项拒绝（逐批独立记录）。
- N=3..129混合批次、多块大小、非整块/奇数、线程1/2/3/4及并行重复。
- 一般稠密SPD N256..10000实际执行，最大原始C oracle504.670秒，全部800,000,008字节严格一致；各批记录图/内核/IO/元数据及二进制SHA。
- N10000完整稠密二进制布局的结构化对角SPD：独立解析oracle逐字节通过，输出约800MB；不代表一般稠密N10000性能。
- 新结构化批次380次严格C对照、46性能，包括半带宽边界127/128/129、符号零/subnormal/FMA tiny下溢，dense Toeplitz/low-rank与2047/2048/2049；最大带宽7 N10000实际原始C约481.611秒，800,000,008字节真值，与一般dense成果分开。
- helper49次C对照＋17项拒绝（另于基础24项），嵌套/prototype/线性SSA/未使用整数检查/不支持返回精度；线程Shape策略38次C对照；4/8/16线程及真实Win32 RAM48次严格运行。
- 计数型while全操作证明63次原C对照，含分块1/7/32/100；改步长/运算留VM；实际bytecode与loop audit保持while。
- 非法长度/N/尾部、非SPD/NaN、块/Metadata/限额、helper副作用、int32溢出与除余/转型、资源图cap等24项拒绝，失败文件未发布且.partial清理。

这些证据证明目前可以执行本地按题面设置的测试；它们不代表官方隐藏测试或最终性能评分。

当前运行时包括真正参数化P/T/U块DAG、闭式后继、packed因子、CPU检测AVX2独立mul/add或显式fma。共享表达式DAG和紧凑指令Metadata保持源语义，helper支持纯SSA多声明。普通N10000需约2GB矩阵/因子工作内存及图/队列，参考比较需2.4GB临时磁盘；结构化Shape测试与普通dense证据分开。
