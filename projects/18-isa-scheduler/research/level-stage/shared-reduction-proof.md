# 共享多行归约的累加器年龄必要下界

仅适用于严格完整结构：R 行，各有 m 个 `MULW(w_j,x_rj)`；权重 GET 身份 w_j 在各行共用，所有 x_rj 为独立私有 GET；每行原 ADD 为 `product_0` 起始、逐项加入 `product_j` 的原有二叉链；每行独立 SET；全部原节点由这些角色覆盖。GET/SET 名称各自唯一且相互不交，不能 alias/recompute/reread/spill/reassociate。操作数左右顺序不必相同，但原有序参数必须保存。要求 0<R<W 且 m>W。

**全部行已启动必在第一 SET 之前。** 若某一行尚未产生 product_0，已产生 GET 的每个权重列都必须保留该权重本身（此行 product_j 未产生），或保留此行已产生且不能归约的 product_j（j>0）。此行没有 product_0，所以不能执行任何原 ADD。每个已出生权重列拥有至少一个互异、未来还需要的身份；数量至多 W。某行完成 SET 要求所有 m 个权重已出生。m>W，故完成第一 SET 时已经没有未启动行。

从最后一行 product_0 发射完后的下一位置，取到第一 SET 发射前的下一位置。每行有一个当前累加器：product_0，或最近已发射的该行 ADD 的输出。它们互异且均需要未来使用。每个 ADD 消耗当前累加器并产生该行新的累加器。这只是在下界证明中跟踪一个逻辑角色，输出仍必须保留所有互异原节点身份。

R 个最新累加器年龄和 S 的范围长度为 R(W-R)。普通原 GET、MULW 均使 S 增长 R。每个 ADD 被引用的累加器副本年龄 d_used<=W，而刷新前最新副本年龄 d_latest<=d_used；角色替换后变化 R-d_latest>=R-d_used>=-(W-R)。COPY 若刷新累加器，同样变化至少 -(W-R)；其他 COPY 只会使 S 增加 R。引用合法较老副本仍满足此不等式，不要求输出只用最新副本。

区间前，选最后一条尚未启动的行。在它 product_0 发射前，已出生的权重列至多 W。属于这些列的权重GET、私有GET和MULW总数至多 (2R+1)W。属于尚未出生权重列的已出生私有GET无法执行MULW，必然仍存活，至多 W。区间前的 GET/MULW 总数因此至多 (2R+2)W。最后启动的 product_0 本身包含在已出生列的计数中。

区间后，第一 SET 所属行已经使用了全部权重，所以不会剩余权重 GET。尚未产生全部行 MULW 的权重列必须保持权重身份；其列数至多 W。剩余 MULW 至多 RW；未产生的私有 GET 至多 RW。因此区间后的 GET/MULW 至多 2RW。这里即使其他行有提前产生、尚未归约的乘积，也只会增加活值压力，不增加未来 GET/MULW 的数量。

全图 GET/MULW 共 (2R+1)m 个。区间内这种非刷新原指令至少

    G=max(0,(2R+1)m-(4R+2)W).

区间内原 ADD 数至多 A=R(m-1)。令全图 COPY 数为 C，则区间年龄和变化至少 R G -(A+C)(W-R)，又不超过 R(W-R)，故

    C >= max(0,ceil(R G/(W-R))-R(m-1)-R).

R=4、W=8 得 C>=max(0,5m-144)。例如 m315、原4095指令，至少1431 COPY，输出分母必要比例1431/(4095+1431)=25.8958%。这是保守界，既不证明3138已最优，也不保证1431能达到。R=4、W>=16 这个界通常为0，与已有逐列零COPY构造相容。

独立 raw-JSON 检查器通过证书的权重/私有GET/乘积/ADD/SET原节点索引，逐条检查每一行的实际有序引用身份、原ADD链与全覆盖；不调用 ParsedBlock、调度器结构识别或输出状态。每个角色节点必须互异（权重是唯一允许跨行共用的身份）。未来COPY只能引用角色的精确原身份；证明不授权原操作或SET/GET数目的变化。
