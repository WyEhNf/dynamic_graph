## 复测

```powershell
.\scripts\test.ps1 -Full
```

默认种子20261010，可通过 `-Seed` 改变。生成器输出包含hardware、nodes、deadline、可选witness_plan；schema在docs/local-case.schema.json。所有数值为整数，JSON支持int64和UTF-8/Unicode字符串，不接受浮点数。

## 可行性证明的范围

随机/层状/链/多sink图由已知拓扑顺序生成。串行witness的显存按Compute开始分配workspace+output、结束释放workspace、最后直接消费者结束释放producer output独立计算；deadline取该合法串行总时间。置乱ID版本使用任意串行拓扑顺序均能容纳的保守内存上界；窄内存版本取已知witness峰值。必须并行的16、64、128、256节点图提供各自并行流witness。测试不是从求解器的成功结果反向挑选。

研究集补充143案开发与143案不同种子持出数据，含37个8/12/16/18节点精确串行最小显存oracle、60个随机结构解析并行witness、27个蝶形/梳形/宽汇聚witness、12个规模梯度串行witness、4个不连通窄内存汇聚和3个官方例。全部witness、返回方案均和独立模型对照；Python解析的witness T/peak还须和独立模拟精确相等。

复测研究：`scripts/research.ps1`，或运行generate_research_cases.py与paired_benchmark.py。输入/源代码/二进制完整SHA-256保留，before基线允许显式无候选，after无候选会令脚本失败。

覆盖仍偏向构造性可行图，没有完整隐藏图分布。当前搜索最多256流，基础唯一评估预算36/96/220，追加策略有独立32/16/8预算；小图DP仅保证串行显存最优，局部性回退限制至10000节点。不能保证所有有解图一定找到结果。失败时保留输入与错误，不把无候选误判为证明无解。
