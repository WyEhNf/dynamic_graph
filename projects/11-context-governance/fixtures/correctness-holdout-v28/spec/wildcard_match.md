Implement wildcard_match(text, pattern). Both inputs must be strings; otherwise raise ValueError. Match the entire text using case-sensitive Unicode code points. In pattern, '?' matches exactly one code point and '*' matches any sequence of zero or more code points; every other character is literal. Consecutive '*' characters have the same meaning as one '*'. There is no escape syntax. Return a bool. Empty text and/or pattern obey these same rules. Return only the complete solution.py file.
