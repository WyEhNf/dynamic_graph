# 两链局部资源 DP 的范围与恢复证明

## 适用条件

当前子树根是一个原 ADD/MULW，有两个不同数据子身份；每个子树严格为
GET 开始、后续每个原 ADD/MULW 的两个有序参数都引用直接前驱的 unary
链。原 GET/SET 各唯一且读写地址集合不交叉，原图无 hazard/order deps、
无共享。未用 GET 仍保留在完整输出末尾，SET 无临时结果但推进物理槽。
其它树节点保留原 DFS 两次序，不能把不匹配/预算耗尽作为全图无解。

## 状态充分性

两链 prefix 为 (i,j)。i>0 时链 A 的唯一未被本链后继消费的当前原身份，
由链列表 A[i-1] 完全决定；B 同理。已经被消费的身份再无数据用户。
所有 external 身份均位于当前子树以外，没有当前子树内消费，必须全部
保留到返回。保存 external 有序 latest-age 向量，再按 A/B 固定角色顺序
保存已出生的当前链值年龄。

允许动作仅为 A 或 B 的下一原指令，prefix0为GET，否则重复引用自身
上一个原身份。原参数顺序与原 opcode 不更改。完整状态决定此动作的
deadline-only COPY 操作、下一年龄向量和 COPY 成本。任何 COPY 携带的
原身份保持不变，没有数值别名、重读 GET、重算或 spill。

## 有界转移与角色恢复

当最老 live 年龄 W 且本条原指令不最后消费它时，把它 COPY 到最新槽；
全部其他年龄+1。COPY 是真实物理槽，不能从计时中略去。当前 unary 原
指令最后消费自己的旧链身份，父二元原最后消费两链最终身份；允许
发射覆盖这些已死亡身份。GET 尚未出生时至少有一个空闲 live 位置，
因为已通过容量需求 k+2<=W 的必要剪枝。

COPY 最老身份只把它轮转到最新，至多 W-1 次应找到死槽或本条 last-use
身份，实现另有 W 次安全界，不能进展仍只称受限失败。
原 `_advance` 删除消费身份后把新结果放最后。每一步立即把前 k 个
external 年龄保留原角色位置，按 A/B 的实际 role 重新排列后缀；并非
按数值排序 external，也不交换其将来的消费身份。

## 局部最小成本边界

每条折叠转移发射且只发射一个原指令，故 i+j 严格增加，形成无环
(L_A+1)*(L_B+1) prefix lattice。只有完全相同 prefix/角色年龄出口可
合并，并保留最低累计 COPY 成本。未来允许动作和资源成本完全相同，
这项合并安全。没有用未证明的分量年龄支配关系。

在该局部 lattice 完整排空、没有时间/state限制时，它给出**这两链逐原
交错且采用 deadline-only COPY 的最小成本，按完整每角色出口年龄条件**。
不允许提前 COPY 的这个候选族，与任意重排/任意 COPY 时机的全局最优
不同。全树其它节点仍有 DFS 限制，且 max_outcomes 截断可能丢掉出口，
因此不能泛称全树最优。100隔离双链 gold 也不能覆盖所有 external 上下文。

资源上界按自由保留 k+active 个角色估计，每 prefix 最多 P(W,k+active)
年龄排列，active<=2；这仍会随 W/k/链长迅速增长，所以默认候选500ms、
20000全局state，限制包括整个 matcher、恢复和 emitter，不保证硬墙时上限。
任何超限是unknown，不返回只完成一部分的输出。

## 原身份恢复

缓存 plan 仅记录 (chain role, prefix offset) 或子树角色计划。真实原
index 从本次调用的真实链列表恢复，不把此前相同 shape 调用的原ID搬入。
所有原节点一次完整 permutation，父 op 的有序参数按真实原 index 映射
到物理最近副本；缓存等价不合并任何原指令。恢复后独立 emitter 复制
最老真实身份，COPY 数必须等于 DP 累计数，否则内部断言失败。随后须
原 JSON 身份/窗口/ordered args/寄存器hazard、符号、三整数重放。

R150完整双链10节点W4反例：全DFS族1COPY，交替两链0COPY，由COPY非负
下界说明该完整例的0是全局最优。这个小反例只证明新增能力的必要性，
不是整个336语料或官方Level成绩。
